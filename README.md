# 📍 Consulta de CEP

Aplicação web simples e responsiva para consulta de endereços a partir de um CEP brasileiro. O usuário digita um CEP e o sistema retorna os dados do endereço correspondente ou informa caso o CEP seja inválido ou não exista.

## 🚀 Tecnologias Utilizadas

- **Next.js**
- **React**
- **TypeScript**
- **Tailwind CSS**

## ✨ Funcionalidades

- Busca de endereço a partir de um CEP.
- Exibição dos dados do endereço (rua, cidade, estado e bairro).
- Mensagem de aviso caso o CEP não exista ou esteja em formato inválido.
- Interface responsiva estilizada com Tailwind CSS.
